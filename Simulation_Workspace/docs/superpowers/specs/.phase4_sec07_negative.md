## 7.2 Generator negative-sequence treatment (normative)

1. The generator enters the negative-sequence network as a series impedance
   `Z2_gen = Ra_pu_mach + j·X2` behind NO internal source: the negative-sequence
   network contains no EMF (prefault is balanced positive-sequence; Task 5
   sources excite the positive network only, Task 12 connects the networks at
   the fault point).
2. `X2 = 0.2242 pu` on the 458 MVA / 22 kV machine base (QUALIFIED
   interpretation, §7.1). `Ra_pu_mach = 0.00089 / Zbase_machine`,
   `Zbase_machine = 22²/458 ohm` (frozen Task 4 §6.3 convention). Ra SHALL be
   retained in the derivation chain; omission in the fault network per stage
   needs the Task 12 justification — never silent (same rule as Task 5 §9.4.1).
3. Base transfer (equation form; implementation evaluates): at the same voltage
   level `Z2_sys_pu = Z2_mach_pu × (S_sys / S_mach)`; across 22 kV ↔ 230 kV
   through the GSUT the implementation SHALL state the voltage-ratio treatment
   explicitly per Task 4 §6.3 rule 3. Converted fault-study NUMBERS are not
   computed here — Task 14 owns them.
4. Saliency / rotor-physics note (design intent, not a second value): X2 for a
   round-rotor turbo-generator physically reflects the average of the
   subtransient d/q paths as seen by a reverse-rotating field; the workbook
   0.2242 value is ADOPTED AS GIVEN, not re-derived from
   `(Xd''+Xq'')/2` or any rotor formula. Any such formula is FORBIDDEN as a
   substitute — the source cell governs.
5. NER exclusion: the 10BAB11 NER impedance (Task 6) SHALL NEVER appear in the
   negative-sequence network — no neutral leg, no 3× factor. The `3·ZN` branch
   is strictly zero-sequence (Task 6 eq. 10-5).
