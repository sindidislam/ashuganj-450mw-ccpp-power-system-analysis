### 22.1 Compactness principles (binding)

1. **Base + OFAT.** ONE base run (§22.2) per prefault case. Each sensitivity leg
   repeats the base with ONLY its named factor changed (same case, dataset except
   where the leg IS the dataset, band end except where the leg IS the band,
   `Xd''` role except where the leg IS the role, `m`, `Zf` except where the leg
   IS `Zf`). Full-factorial combination, Monte-Carlo sampling, random sampling,
   optimiser sweeps, and parameter grids are FORBIDDEN.

   in §22.4 (S3+S4 for `B22` LG, L1+H3 at `B6_6`, C×B ends conditionally, `Zf`×topology
   per §22.3-F/G). Any other cross-product needs a recorded technical reason and
   Task 14/15 review — never silent.
3. **Status discipline.** Every variant below carries value + unit + base + source +
   locator + closed-enum status + rationale. NOTHING adopted as ENGINEERING_ASSUMPTION
   is presented as measured; MISSING stays MISSING (carried as a bounded alternative,
   never promoted).
4. **Budget.** The matrix is the A–H legs of §§22.3-A–22.3-H NOTHING more in the base
   matrix. Extra values MAY be added ONLY via §22.4 with recorded reason — never an
   uncontrolled sweep (Task 12 §21.2-c pattern).
5. **GAT IN/OUT gating preserved under every leg** (Task 8 §13.5.1): `GAT_OUT` = GAT
   branch OPEN all sequences (leg ABSENT, not zero-filled); `GAT_IN` = branch CLOSED
   per §13.3 with H-legs applied. NEVER one shared GAT state across the OUT/IN pair.
6. **Prefault-case fence** (Task 5 §9.2): base EMFs are `LF360_GAT_OUT` / `LF360_GAT_IN`
