01 / Quick start

Open and run

Use Phase6/START_PHASE6.m. The v4 working model is Phase6/PHASE6_ASHUGANJ_CCPP_CLOSED_LOOP_TRIP.slx.

Academic simulation with declared engineering assumptions. See Assumptions and limits for the scope of its results.

1

Check the environment

Use MATLAB R2024a, Simulink, Simscape, and Simscape Electrical with Specialized Power Systems (sps_lib, powergui, and power_loadflow). Keep the complete v4 folder together: the SLX needs its local MATLAB functions and frozen reference CSVs. The documented environment is Windows; other releases are not covered by the current verification evidence.

2

Start from the correct project

Paste this into the MATLAB Command Window. Change only projectRoot if you move the folder.

projectRoot = 'C:\Users\sindi\Downloads\Simulation_Workspace\Simulation_Workspace';
cd(projectRoot);
run(fullfile(projectRoot,'Phase6','START_PHASE6.m'));

The start script loads the saved model and opens its study panel. Double-click Controls on the model to reopen that panel. Opening preserves saved settings; choose Reset defaults for a clean baseline.

3

Run the baseline

In the control window, choose Reset defaults, then Run simulation. Defaults are 360 MW on the finite-impedance PHASE5_STUDY profile, no fault, GAT out of service, and protection/battery/charger available. Reset changes settings; it does not itself run a simulation.

Open Measured voltages and currents. Its table is the last sample of the latest completed run. A healthy 22 kV bus has about 12.70 kV phase RMS in Va/Vb/Vc; the plant summary reports approximately 22 kV as a balanced-equivalent line voltage. Frequency is calculated from rotor speed.

4

Save evidence

Give each retained run a distinct scenario name and choose Export results. Exports go to Phase6/results/<scenario-name>/. Reusing a name replaces generated files in that scenario folder. Use Run simulation in the study panel when you intend to use its results table, plotting button, and export button.

First fault demonstration: choose 3PH at GIS230, start 0.150 s, duration 0.300 s, stop 0.600 s, with protection and DC sources available. Run, select Fault bus, and plot V/I waveforms. Then export and inspect relay_times.csv and breaker_times.csv.

Printing: this manual has an A4 print layout. Expand the column-reference sections before printing if your browser does not reveal collapsed details automatically.

The network uses a 50 µs discrete electrical step and the synchronous machine’s Trapezoidal robust method. Its physical load flow initializes the electrical state and the governor/AVR. Electrical component walkthrough

powerguiConfigures the Specialized Power Systems electrical solution and initialization: 50 Hz, 50 µs discrete step, and 100 MVA reporting base. It is a simulation infrastructure block, not physical plant equipment.
Generator / Synchronous machineRound-rotor synchronous machine with electrical transient states, inertia, mechanical-power input and field-voltage input. The selected machine base is 458 MVA, 22 kV. Load flow sets its initial operating point. Its measurement bus supplies rotor speed, dq terminal voltage and native delta to the control/recording subsystem.

Numerical terminal shuntA 10 W nominal constant-impedance shunt helps the circuit representation. It is a declared numerical load, not an installed generator accessory.
Generator Breaker (GCB)Three-phase electrical switch between the generator and the common GSUT/UAT-side connection. An external command from Breaker Control operates it. Opening disconnects the generator from external paths; it does not remove the GEN fault branch beside the machine.
Transformer / GSUT 10BAT10Two-winding generator step-up transformer, 515 MVA and 230/22 kV, YNd1. It transfers generator power to the switchyard and imposes a vector-group/zero-sequence relationship. The HV wye and LV delta must be accounted for before comparing differential currents.

Bus incoming CT / Line feeder CT / GAT feeder CT / GIS bus faultThree current boundaries around the bus produce IbusIn − IbusOut − IgatHV for 87B. The GIS230 fault lies inside that zone. GAT current remains part of the balance even when its breaker is initially open.
Transmission Line / four PI sectionsTwo parallel 0.7 km circuits, each split into plant and remote halves. The LINE230 fault is at the midpoint of circuit 1. Resistance, inductance and capacitance use the selected positive/zero-sequence profile. Both circuits share the modeled local/remote breaker sets and aggregate CTs.
Local line breaker / Remote line breaker / CTsActual three-phase switches at both line ends. Synchronized end currents feed 87L; its demand opens both ends. The relay includes a 5 ms aggregate communication/processing allowance; it does not simulate channel packets, asymmetric delays, or individual circuit breaker hardware.
Grid / Grid CT and VTMeasures voltage and signed current at the remote terminal boundary. P/Q derived here are CT-boundary powers; account for the series equivalent before comparing with source-boundary load-flow powers.
Grid sequence impedance / PGCB voltage source / Remote bus faultA mutual-inductance Z1/Z0 element represents selected grid sequence impedance in front of an ideal grounded 230 kV, 50 Hz swing source. GRID230 is an external remote-bus fault. The source is a short-circuit/load-flow equivalent, not a dynamic model of the wider PGCB grid.
Auxiliaries / UAT 10BBT10Feeds the common auxiliary bus from the 22 kV unit connection. Its modeled secondary winding is 6.9 kV; loads are rated at the 6.6 kV switchboard. These are distinct rating/operating labels, not a typo to eliminate.
Auxiliaries / GAT 10BBT20 and GAT incomerAlternative feed from the 230 kV switchyard. The GAT switch begins open in LF360_GAT_OUT. Enabling it changes the physical supply topology and requires a new load-flow solution.
UAT/GAT neutral resistorsSeparate 5 A grounding equivalents on the 6.9 kV winding basis: (6900/√3)/5 ≈ 796.74 Ω each. They are not the generator’s 1,750.77 Ω resistor and are not solid grounds.
Auxiliary bus CT and VT / load blocks / bus faultAggregate included loads total 14 MW at 0.85 power factor using constant-PQ, floating-star equivalents. AUX66 applies a fault on that bus. The auxiliary sensor also supplies the charger-availability calculation; it is located in the modeled load branch, so interpret its current boundary accordingly.
Fault switches and numerical snubbersOnly the selected fault branch follows the requested on/off schedule; inactive switches are scheduled far beyond the run. Finite fault/snubber resistances support the SPS representation and can leave small leakage currents. They are not measured plant insulation or arc models.

Control, protection, and recording component walkthrough

ComponentInputs → function → outputs
MeasurementsCollects 19 V/I sensor groups. Optional measurement test factors multiply V and I before a synchronized one-cycle RMS/DFT calculation. It logs unscaled raw samples separately, produces scaled RMS and complex phasors, and gates relay operation until a complete acquisition window is ready.
Protection / Pickup and relay timingPhasors + ready flag + exact R/S settings → seven current-based elements → pickup, timing, trip diagnostics and breaker/unit requests. No fault-scenario flag is used to fabricate relay operation. The individual elements are explained below.
DC Supply / AC supply magnitudeAuxiliary phase waveform RMS → √mean(Vabc²) × √3 / 6600. This aggregate measured magnitude and the charger checkbox determine AC availability. It is not a positive-sequence voltage calculation.
Battery charger and DC busAC availability, source-availability settings and aggregate trip demand → nonlinear DC power balance with battery resistance, charger current/power limits, SOC integration and voltage/service checks → Vdc, source/load currents, SOC, alarms, charger AC watts, and supplied coil watts.
Trip coil demandCombines breaker/unit requests into one rising-edge-triggered aggregate trip pulse. Pending pulse time is preserved while useful DC service is unavailable. This is an energy approximation for the initial trip, not independent wiring for every physical coil.
Breaker Control / DC trip path and mechanismRelay/manual requests + healthy DC → 50 ms mechanism timers → five latched closed commands and unit-trip output. Failed-breaker scenario flags prevent selected openings. A new simulation resets the latches and initial states.
Turbine and AVR / Governor turbine and AVRRotor speed and measured dq terminal-voltage magnitude feed a droop governor with governor/turbine lags and a limited AVR with response lag. Outputs drive the machine’s real Pm/Vf ports. Unit trip drives target valve and field commands to zero through those lags, rather than instantaneously deleting machine energy.
Results / Plant quantitiesLogged phasors, machine state, relay flags, breaker commands and DC diagnostics → 24 labeled plant channels. Scopes and canvas indicators display these quantities; CSV/MAT export uses original logged data and explicit measurement windows.
Goto/From, Mux, selectors, gains, To WorkspaceRoute, order, select, scale and record signals. The named P6_* tags connect subsystems without long canvas wires. They are signal plumbing, not extra electrical equipment or independent protection functions.

Two different relay studies exist. The v4 analytical 87G/87T documents describe different slopes, high-set stages, and harmonic restraint. The dynamic model above has high-set disabled, no harmonic blocking, and no CT saturation model. Do not describe those analytical features as active Simulink protection.

For steady current above pickup, IEC Standard Inverse time is t = 0.14 × TMS / ((I / pickup)^0.02 − 1). With varying current, the simulated overcurrent relay integrates dt / t(I) until accumulated duty reaches 1. Below pickup, an untripped timer resets. Trips latch for the run. A differential relay requires measured spill to exceed the larger of its pickup floor and its bias/restraint threshold continuously for its delay; the transformer uses YNd1 compensation and HV zero-sequence removal.

What each of the seven relay elements does

ElementMeasured operating quantity and behavior
GEN51Largest fundamental phase-current magnitude at generator terminal CT. Above 17,170.8 A it accumulates IEC SI inverse duty; its unit trip requests GCB/Q0 opening and controller shutdown. It is phase-overcurrent backup, not the generator differential element.
GSUT51Largest HV phase-current magnitude at gsutHV. Its 1,380 A pickup and TMS 0.55 use the HV primary basis. It requests the same unit isolation path.
GEN51NMagnitude of the physically measured generator neutral current, using its assumed 20/1 CT. It detects low-level earth-return current with 4 A primary pickup and inverse-time delay; it does not use the maximum phase current or substitute a magnitude sum for neutral current.
87G generator differentialPer-phase |IgenInner − IgenTerminal| is spill. A healthy through-current ideally cancels; a fault between the CT boundaries produces spill. Restraint is half the sum of the two current magnitudes. The active model uses a 2,403.8 A floor, 30% slope and 45 ms delay.
87T transformer differentialCompares LV current converted to the HV/vector basis with HV current after zero-sequence removal. This avoids interpreting normal transformer ratio/phase shift as a fault. The active model uses a 387.84 A HV floor, 30/60% slopes, a 2×1,292.8 = 2,585.6 A restraint knee, and 45 ms delay.
87B bus differentialPer-phase signed KCL spill |IbusIn − IbusOut − IgatHV|, with half-sum restraint over all three boundaries. Its 320 A floor, 30% slope and 35 ms delay request Q0/local-line/GAT isolation of the bus.
87L line differentialPer-phase |IlineLocal − IlineRemote|, with half-sum restraint. Its 320 A floor and 30% slope request both line-end breakers after 35 ms local detection plus a 5 ms aggregate communication/processing allowance. Currents remain synchronized phasors. The added timing allowance does not delay one end’s samples or model channel failure or charging-current compensation.

Active differential threshold and compensation

All currents in the following equations are complex RMS fundamental phasors with the polarity defined by the sensor wiring. For each phase, the dynamic algorithm uses:

Irest = 0.5 × sum(abs(each zone-boundary current))
threshold = max(pickup_A,
    slope1 × min(Irest,knee_A) + slope2 × max(Irest-knee_A,0))
pickup = abs(compensated signed current sum) > threshold

The differential timer runs separately for each phase; an unpicked-up phase’s timer resets. Any phase remaining above its threshold for the specified delay latches that element’s trip. The exported scalar differential/restraint/threshold channels come from the same phase with the greatest operating margin, so they remain one coherent operating point.

For the YNd1 transformer the compensation is:

I_LV_as_HV = (22/230) × [Ia-Ib, Ib-Ic, Ic-Ia] / sqrt(3)
I_HV_without_zero_sequence = I_HV - mean(I_HV)
Ispill = I_LV_as_HV - I_HV_without_zero_sequence
Irest = 0.5 × (abs(I_LV_as_HV) + abs(I_HV_without_zero_sequence))

For 87G, 87B and 87L the two slopes are equal, so the stored knee does not change the characteristic. In 87T it separates the 30% and 60% regions. A slope is meaningful only with its current base and restraint definition; a 30% half-sum characteristic cannot be compared directly with a 30% full-sum characteristic.

Hands-on: rerun the same fault with a changed protection setting

  1. Choose Reset defaults. In Operating point and faults, enter scenario name bus_delay_35ms, generation 360 MW, 3PH, GIS230, start 0.150 s, duration 0.300 s, stop 0.600 s. Keep protection, battery and charger enabled; DC loss/restore are both Inf and GAT is out.
  2. Open Protection settings. Leave the Bus 87B row enabled with pickup 320 A primary, CT ratio 1600, delay 0.035 s, and slopes 0.30 / 0.30. Leave other rows at defaults.
  3. Click Run simulation, then Export results. Inspect Phase6/results/bus_delay_35ms/relay_times.csv for 87B and breaker_times.csv for Q0/LineLocal. The September 25 v4 reference run recorded the request at 0.187 s and commands at 0.237 s.
  4. Change only the scenario name to bus_delay_100ms and the Bus 87B Delay (s) cell to 0.100. Click Run simulation; it applies the edited values before running. Export again.
  5. Compare the two runs. The September 25 v4 check measured a 0.065 s shift: the edited request/open times were 0.252/0.302 s. Check your own exported timestamps against this reference; additional changes can alter the response.
  6. Read scenario_metadata.json and the MAT file’s info.controls.relayParameters for the actual settings; compare measured fault-branch waveforms and current cessation as well as commands. The longer delay should retain physical fault current longer.
  7. Choose Reset defaults, rename the normal run if retaining it, and run again. This restores the study setting and starts fresh relay/breaker states.

05 / Change parameters

Know where an edit takes effect

Each full scenario export contains 16 CSV tables, simulation_data.mat, scenario_metadata.json, and five figure pairs (PNG and raster PDF, both at 220 dpi):

  2. 02_speed_power — rotor speed and generator/grid CT-boundary P/Q.
  3. 03_fault_waveforms — configured fault branch’s measured voltage, instantaneous current, and waveform RMS.
  4. 04_protection_breakers — pickups, requests, closed commands, and overcurrent secondary diagnostics.
  5. 05_station_dc — DC voltage, currents, SOC, and availability alarms.

Timing and missing-event conventions

  • The original time histories retain startup. Tables, event extraction and plots exclude samples before 0.020 s. The 50 Hz phasor/RMS chain needs a 20 ms acquisition window and adds a 1 ms stored-output delay.
  • Each CSV uses its own logged timebase. Do not subtract row indices between files; compare their Time_s values.
  • An initial fault waveform metric uses samples from scheduled fault start up to the earliest of +20 ms, scheduled removal, the first observed opening command, or record end. A shortened interval is labeled as partial.
  • A fully post-fault phasor window is first eligible at fault start +21 ms. The fundamental summary uses eligible windows before +60 ms, opening, scheduled removal, or record end. Waveform RMS includes DC offset and harmonics; the fundamental phasor excludes them.
  • Current cessation requires unscaled raw |I| ≤ max(1 A, 0.001 × pre-command 20 ms peak |I|) continuously for 20 ms after an opening command. Its timestamp is the beginning of the subsequently confirmed interval. A single AC zero crossing cannot qualify.
  • If a relay did not operate, a breaker never opened, or current continued through the end of the run, its event table says so in Status. No event time is invented. The numeric timestamp is stored as NaN when that event was not observed; this does not mean a required circuit parameter is missing. Inf in an overcurrent operating-time channel means the present current does not produce a finite trip time. JSON uses null for nonfinite numbers; the MAT file retains their exact numerical distinction.
Do not equate current types. Fault-current columns use the configured fault branch. The summary channel Fault_I_kA is only the maximum fundamental phase magnitude across all seven fault sensors. For fault reporting use fault_summary.csv and the named branch channels. Also, generator-zone branch interruption does not prove the rotating generator has stopped supplying its own fault.

08 / Assumptions and limits

Study assumptions and scope

Source-backed Generator ratings/reactances and selected transformer records are traced to project documents. Study choice A finite numerical value can make the simulation run without making that value an installed-plant fact. The source/assumption register preserves that distinction.

ItemWhat is implemented / practical resolution
Two network profilesUse the default PHASE5_STUDY for new v4 fault runs: grid R1=0.267344 Ω and X1=2.938108 Ω, with declared finite zero-sequence values. The legacy PHASE3_BASELINE preserves its old balanced load-flow assumptions for deliberate historical comparisons; its Rgrid=0 is unsuitable for unqualified DC-offset/peak-current claims. Frozen Phase 5 fault CSVs contain the older Phase 4 backbone, so compare quantities and profiles explicitly rather than forcing dynamic curves to match.
Initial fault-current comparisonFrozen Ik″ and later dynamic fundamental RMS differ in time window, network assumptions, and machine state. Existing comparison documents disclose material differences. Report the actual interval and profile; a curve match is not an independent plant validation.
CT core data and saturationActive measurements use ideal synchronized phasors. GSUT HV 1600/1 is the central study choice; 1500/1 is a documented alternative. Missing excitation curves, burden, remanence, and core/tap confirmation prevent quantitative saturation validation. Exceeding 20× rated current for a 5P20 core is a qualification flag, not proof of the exact saturation waveform or its onset. Obtain the actual core data and build/test that model before making saturation-security claims.
Differential high-set / harmonic blockingThese stages are not active in the dynamic implementation. Use this model for its implemented biased fundamental-current scheme. Harmonic restraint and high-set security require explicit implementation and validation. The 87L calculation includes a finite 5 ms aggregate communication/processing allowance, not a detailed channel simulation. Analytical Phase 5 examples do not add live dynamic functions to the SLX.
Grounding and stator protectionA passive generator zero-sequence/neutral equivalent plus one physical resistor represents terminal behavior. It is not a winding-resolved stator model or the actual NGT. GEN51N measures fundamental neutral current; it does not implement 64G 20 Hz injection or demonstrate 100% stator-earth coverage. Retain derived Rn until qualified NGT/loading-resistor and injection-test data are available.
Generator-side fault clearingOpening GCB/Q0 isolates measured breaker branches, while stored machine energy may continue feeding the generator-side fault. Observe faultGEN through scheduled removal. Complete de-excitation, winding-fault extinction, and long-duration stability are not established by the short acceptance runs.
Breaker capability / 50BFActual SPS switches use assumed 50 ms mechanisms, finite on-resistance and numerical snubbers. There is no contact feedback, detailed arc/TRV model, or implemented breaker-failure backup relay. Q0 rating/nameplate mapping, contact-parting/DC/TRV capability, and the separate 400 kV regional envelope remain hardware verification items; South’s modeled switchyard is 230 kV.
Station DC / multiple coilsThe 110 V bank, SOC curve, charger and 2 kW initial trip pulse are an academic equivalent. The pending initial request waits for healthy supply, but individual coils are not wired or metered independently. A later trip while aggregate demand remains high does not create a new coil pulse; manual commands bypass aggregate coil demand. Limit energy conclusions to the demonstrated initial protection trip/recovery.
Auxiliary loads / motors / low-voltage detail14 MW is represented at 6.6 kV using aggregate floating-star loads. Excluded 400 V demand is already inside that total; missing feeder details are not attached as invented loads. No claim of individual motor transient contribution or 400 V terminal voltage follows. Add qualified equipment data and voltage-conversion topology for those studies.
Controllers and numerical equivalentsGeneric AVR/governor/turbine tuning, finite machine viscous-loss coefficient F=0.001 pu, the source behind finite grid impedance, assumed sequence impedances, omitted line mutual coupling, shunts and snubbers are explicit representation choices. Historical source tables also retain unused or excluded documentary fields; those are not silently connected to the simulation. For example, the machine uses its configured pu field dynamics rather than an unqualified raw field-resistance entry, and the 400 V load allowance remains inside the 14 MW aggregate. Extend the model only with an explicit chosen value, physical basis and source.

Use only the seven implemented functions for dynamic claims; commissionable settings need actual device files and wiring review.

The central study/installed-document register explains outstanding document verification. Operationally, continue the declared numerical study where a traceable choice exists, keep the affected claim conditional, and replace that choice only after reviewing actual plant data. An absent measured event, such as “no current cessation within this run,” is an observation status—not a missing numerical parameter.
