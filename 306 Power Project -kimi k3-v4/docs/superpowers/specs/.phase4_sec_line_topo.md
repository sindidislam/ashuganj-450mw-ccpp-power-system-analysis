## 18.2 Decision: lumped (A) vs explicit circuits (B) — binding

**DECISION: base network = lumped equivalent (A); explicit two-branch view (B)
is a DERIVED reporting projection of the same frozen total — never a second
impedance source.**

Rationale (simplest technically valid):

1. Phase-3 froze ONE modelled branch (`L_LINE`, 2 modelled branches total with
   `ZGRID`; Task 1 §3). The fault study SHALL solve bus faults F1/F2/F3/F5 on
   that exact lumped topology — zero new impedance, zero re-tuning, full
   prefault/fault topology consistency.
2. Per-circuit currents (protection-stage handoff) and single-circuit line
   faults NEED a two-branch view. That view is obtained by EXACT algebraic
   split of the frozen total (§18.3) — no new data, no mutual matrix, no
   second calibration.
3. A fully independent two-circuit model with mutual impedance (Z0m) is NOT
   supportable: no geometry, no measured R0/X0, GIS drawing MISSING (Task 2).
   Task 9 §14.4 already rules mutual ignored-by-construction; this section
   inherits that ruling and states its consequence for line faults (§18.5.4).

Binding rules:

1. The SOLVER base for every bus fault (F1/F2/F3/F5) and for the unfaulted
   state is the lumped branch: `Z_eq = R_eq + j·X_eq`, `B_eq`, endpoints
   `B230_1 → B230_REMOTE` (positive/negative; zero uses Task 9 band via
   eq. 14-2 scaled totals `R0_eq/X0_eq/B0_eq`).
2. View B is DERIVED on demand for (a) per-circuit current reporting at any
   location the line feeds, and (b) single-circuit South-line faults (F4).
   Its branch values come ONLY from §18.3 — implementation SHALL assert
   parallel(B1‖B2) ≡ lumped total to solver tolerance before any fault run.
3. FORBIDDEN: modelling B1+B2 as two full `Z_eq` branches in parallel (halves
   the impedance — double-count in reverse); modelling lumped + explicit
   simultaneously in one network (double-count); assigning different per-km
   constants to B1 vs B2 (no source; symmetry is the locked basis).

## 18.3 Split rule (equivalence-preserving, binding)

For EACH sequence s ∈ {1, 2, 0}, let `Zs_eq`, `Bs_eq` be the frozen (s=1,2)
or Task-9-band (s=0) LUMPED totals. Explicit branches B1, B2:

```text
(18-1)  Zs_B1 = Zs_B2 = 2 × Zs_eq        (series R + jX; per sequence)
(18-2)  Bs_B1 = Bs_B2 = Bs_eq / 2        (total shunt per branch; PI halves
        Bs_Bk/2 at each branch end, k = 1, 2)
(18-3)  Zs_eq ≡ Zs_B1 ‖ Zs_B2 ;  Bs_eq ≡ Bs_B1 + Bs_B2     (assert, all s)
```

Consequences (implementation SHALL enforce, Task 12 consumes):

1. Healthy (both circuits in service, no line fault): each branch carries
   HALF the total line current under the equal-sharing assumption
   (`I_B1 = I_B2 = I_total / 2`). Nominal-scale anchor (NOT a result):
   total ≈ 870 A → ≈ 435 A/circuit — protection-stage per-circuit use only.
2. Equal-sharing is an ENGINEERING_ASSUMPTION (identical parallel branches,
   same endpoints, no transposition/geometry data to do otherwise). Its error
   direction is bounded: any real asymmetry SPLITS the half, it cannot change
   the total — bus-fault totals are invariant to sharing; only per-circuit
   breaker/CT legs move, inside a ±tolerance Task 13 MAY probe but SHALL NOT
   sweep blindly (compact matrix only).
3. Base conversion: all splits are performed in per-unit on the frozen study
   base (100 MVA / 230 kV, Zbase = 529 ohm) OR in ohms with the same base —
   never mixed. Zero-sequence split uses the SAME equations on the Task 9
   band ends (LOW/MID/HIGH each split independently; band ends never averaged
   across the split).

## 18.5 Line-fault division at m (Q13) — binding formalism

### 18.5.1 Definition of m

`m` = fractional distance from the South GIS end (`B230_1`) toward
`B230_REMOTE`, `0 ≤ m ≤ 1`. Mandatory evaluation set (if practical):
`m ∈ {0, 0.25, 0.50, 0.75, 1.00}`; minimum acceptable subset `{0, 0.50, 1.00}`
with the reason recorded (solver-node or band-run budget — never silent).
`m` is per-unit of the FROZEN 0.7 km (physical km = m × 0.7, informational only).

### 18.5.2 Series division (all sequences)

For sequence s with lumped total `Zs_eq` (s=1,2 frozen; s=0 Task-9 band total):

```text
(18-4)  Zs_S(m) = m · Zs_eq        (GIS-end side: B230_1 → fault node)
(18-5)  Zs_R(m) = (1 − m) · Zs_eq  (remote-end side: fault node → B230_REMOTE)
(18-6)  Zs_S(m) + Zs_R(m) ≡ Zs_eq  (assert at every m, every s, every band end)
```

s = 1 and s = 2 divide with the SAME m rule on their respective totals
(`Z2_eq = Z1_eq` per Task 7 element-justified equality — Task 7's ruling,
consumed here unchanged).

### 18.5.3 Shunt division (PI-preserving)

Each m-section is its own PI (total shunt preserved):

```text
(18-7)  Bs_S_total(m) = m · Bs_eq ;  Bs_R_total(m) = (1 − m) · Bs_eq
        GIS-end node keeps m·Bs_eq/2; remote-end node keeps (1−m)·Bs_eq/2;
        fault node takes m·Bs_eq/2 + (1−m)·Bs_eq/2 = Bs_eq/2.
(18-8)  End + fault shunts sum ≡ Bs_eq at every m (assert).
```

For explicit-circuit (B-view) line faults, apply (18-4)–(18-8) INDEPENDENTLY
per branch on the branch totals (§18.3): faulted branch splits by m;
healthy branch stays whole (`Zs_B_healthy = 2·Zs_eq` end-to-end, shunt
`Bs_eq/2` total). The lumped-base cross-check: with both branches healthy,
(18-3) holds; with one branch faulted at m, NO lumped equivalence is claimed
— solver runs the true two-branch network; Task 12 owns the node).

### 18.5.4 Zero-sequence + mutual-unavailable approximation (binding)

1. Zero divides by the SAME (18-4)–(18-8) formalism on the Task 9 band totals
   (`R0_eq/X0_eq/B0_eq` per band end LOW/MID/HIGH — each end divided
   independently, never averaged).
2. Mutual coupling between the two circuits (`Z0m`) is UNAVAILABLE (no
   geometry, GIS drawing MISSING) and therefore IGNORED-BY-CONSTRUCTION
   (Task 9 §14.4, inherited): the two explicit branches are modelled as
   magnetically INDEPENDENT parallel paths. This is an ENGINEERING_ASSUMPTION
   with a STATED error direction: real double-circuit mutual LOWERS the
   effective zero-loop impedance for common-mode earth return, so ignoring it
   OVERSTATES `X0_loop` and UNDERSTATES LG/LLG earth-fault current — i.e. it
   is NON-CONSERVATIVE for earth-fault duty. Mitigation is mandatory
   sensitivity, not a correction factor: Task 13-C runs LOW vs HIGH band ends
   at every LG/LLG location the line feeds, which brackets the mutual error
   inside the honest-and-wide short-link band (Task 9 §14.2 rationale: 0.7 km
   absolute ohms stay small under ANY ratio).
3. FORBIDDEN: inventing a `Z0m = k·Z0` coupling factor as fact; importing
   `X0 = 3·X1` as a division input (Task 9 §14.7).

### 18.5.5 Endpoint-coincidence rule

`m = 0` (line-side GIS end) and `m = 100 %` (line-side remote end) are
LINE faults reported separately from bus faults F3 / F5 at the same
electrical node group: implementation SHALL run both and Task 13 SHALL use
their continuity (`lim m→0` line fault ≡ F3 line-side contribution structure;
`lim m→1` ≡ F5) as a validation leg — never merged into one row, never
averaged.

### 18.5.6 What "line-location support" obliges implementation to provide (Q13)

1. Movable fault node on `L_LINE` at any mandated m with series/shunt split
   per (18-4)–(18-8), per sequence, per band end.
2. Faulted-circuit vs healthy-circuit branch currents for F4 (B-view),
   plus total-line current; direction convention (GIS→remote positive) fixed
   once and used for all m (Task 12 contribution table).
3. m-continuity evidence (F3↔m=0, F5↔m=1) as Task 13 validation input.
