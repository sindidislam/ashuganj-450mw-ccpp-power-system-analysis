## 15.1 Dataset-separation rule (binding — read first)

1. There are exactly TWO grid datasets. Each is a closed profile: its Ik'',
   its |Z|, and its R/X split travel together and are NEVER recombined across
   datasets. No third "consensus" pair (e.g. 50 kA with X/R = 10.99, or 45.01 kA
   with |Z| = 2.65581124 ohm) SHALL be constructed, tabulated, plotted, or
   passed to the implementation.
2. Dataset P (PRIMARY fault-study candidate): Siemens ESTIMATED 50-kA set
   (§15.4). Every figure derived from it inherits ESTIMATED confidence.
3. Dataset S (SENSITIVITY ONLY): secondary 45.01-kA / X/R 10.99 set (§15.5).
   Source status LEGACY; derived figures are DERIVED-inside-secondary-profile
   at c = 1. Sensitivity use only.
4. The Phase-3 load-flow grid profile (R = 0, X = 2.65581124 ohm) is a THIRD
   object of a different kind — a BALANCED LOAD-FLOW ASSUMPTION (Q1a), not a
   dataset — and is fenced in §15.6. It SHALL NOT be counted, cited, or swept
   as a fault-study alternative.

## 15.3 Conversion equations (binding — implementation evaluates)

```text
(15-1)  Sk''  = √3 · V_LL · Ik''            [MVA; V_LL in kV, Ik'' in kA]
(15-2)  |Z_grid| = V_LL² / Sk''  (= V_LL / (√3 · Ik''))   [ohm]
(15-3)  R_grid  = |Z_grid| / √(1 + (X/R)²)   [ohm, within ONE dataset]
(15-4)  X_grid  = R_grid · (X/R)             [ohm, within ONE dataset]
```

Rules: `V_LL = 230 kV` throughout; voltage-correction factor `c = 1` stated for
every S-row conversion (the S7 `c ≈ 1.10` figure is fenced separately and SHALL
NOT leak into S3–S6). Equations (15-3)–(15-4) SHALL be applied with the X/R
belonging to the SAME dataset as the |Z| (§15.1.1). Pu reporting (equation form;
implementation evaluates): `Z_pu = Z_ohm / 529` on the frozen 100 MVA / 230 kV
base (Task 1). No converted fault-study R/X ohms are fixed in this draft beyond
the quoted S3–S5 input conversions — the primary split of §15.6 is evaluated by
the implementation.

## 15.6 R/X treatment (binding — the Q10 core)

1. Phase-3 `Rgrid = 0` fence: rows L1–L2 are a BALANCED LOAD-FLOW ASSUMPTION
   ONLY (Q1a, infinite X/R, lossless remote infeed for balanced power flow).
   It SHALL NOT be carried into ANY fault sequence network — positive,
   negative, or zero. Error direction if violated: R = 0 maximises the X share
   at fixed |Z| and drives the peak/momentary factor κ toward its ceiling,
   OVERSTATING `ip` while understating resistive damping — non-conservative for
   duty. Task 7 §7.5 and Task 9 §8.6 already fence it out of their networks;
   this section fences it at the source.
2. Primary fault-study R/X (dataset P): MISSING as data (row P5) → adopted as a
   BOUNDED ENGINEERING_ASSUMPTION reference band (not a measurement):
```text
(15-5)  (X/R)_P ∈ [10, 20],  representative base (X/R)_P,base = 15
        (arithmetic band centre — a stated representative for a single base
        run, NOT a measurement, NOT an optimum, NOT endorsed physics).
        R1_P = |Z1_P| / √(1 + (X/R)_P²),  X1_P = R1_P · (X/R)_P   [ohm]
        with |Z1_P| = 2.65581124 ohm FIXED (row P3); only the split varies.
```
   Band justification (why [10, 20]): a meshed 230-kV transmission Thevenin
   viewed from a grid bus exhibits high X/R (large-section conductors, many
   paralleled infeeds, transformer leakage dominant); below 10 would require
   distribution-level resistance dominance or long radial feeder physics (no
   evidence — contradicted by PGCB meshed practice); above 20 would require
   near-ideal reactive plant with negligible network resistance (contradicted
   by the finite 45.01-kA-set reading 10.99 in the same family). The band spans
   the plausible transmission extremes and is WIDE by necessity — narrowing it
   would require the missing grid test record. Base run uses 15; band ends 10
   and 20 ride Task 13-A as labelled alternatives (LOW end = highest R =
   most damping; HIGH end = lowest R = least damping).
3. Coincidence note (not a merge): the secondary 10.99 lies just inside
   [10, 20]. That does NOT endorse 10.99 as the primary X/R, does NOT authorise
   pairing 10.99 with the 50-kA |Z|, and does NOT narrow the band — same
   coincidence discipline as Task 9 §14.3 (`kX = 3.0` inside its band).
4. Sensitivity fault-study R/X (dataset S): FIXED at the profile's own 10.99
   (rows S2/S4/S5) — no band, no alternative split. Dataset-S uncertainty is
   exercised by P-vs-S comparison (Task 13-A), not by perturbing 10.99.
5. Consistency envelope (diagnostic the implementation SHALL report): for
   dataset P, realised `X1_P/R1_P` SHALL equal the admitted `(X/R)_P` exactly
   (eq. 15-5 is an identity, not a fit); any leg yielding otherwise is a
   modelling error. For dataset S, `X/R = 2.938108/0.267344 = 10.99` checks the
   S4/S5 arithmetic.
