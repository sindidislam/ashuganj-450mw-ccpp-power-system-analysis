## 17.0 Common conventions (binding for every fault type and stage)

### 17.0.1 Bases, units, operator

1. Study base for the 230-kV network: 100 MVA / 230 kV, `Zbase = 529 ohm`
   (frozen, Task 1). Machine-level quantities live on 458 MVA / 22 kV and
   transfer per Task 5 §9.4.5 (voltages numerically unchanged at the same
   voltage level; impedances scale by the S-ratio; cross-voltage treatment
   stated explicitly at implementation).
2. Fault impedance in physical ohms converts by the base of the voltage level
   where the fault sits: `Zf_pu = Zf_ohm / Zbase_level`
   (`Zbase_230 = 529 ohm`; `Zbase_22 = 22²/100 = 4.84 ohm` on the study base).
   Implementation SHALL state the level base beside every `Zf_pu`.
3. Complex operator `a = e^{j·2π/3} = −1/2 + j·√3/2`, `a² = e^{j·4π/3}`,
   `1 + a + a² = 0`. Angles in radians in equations (deg → rad at I/O).
4. Every reported current SHALL carry exactly one stage label
   (§19): `RMS-symmetrical-initial (Ik'')` | `peak-first-peak (ip)` |
   `RMS-breaking-delayed (Ib)` | `RMS-sustained (Ik-steady)`. Mixing labels
   (e.g. quoting `ip` as RMS, or `Ib` as a peak) is REJECTED. Peak is kA
   instantaneous; all others are kA RMS symmetrical. Phasor angle is carried
   for RMS symmetrical quantities; `ip` is a magnitude only.

### 17.0.2 Reference phases, prefault drive, sourceless networks

1. Reference faulted phase is A for LG; faulted pair is B–C for LL/LLG.
   Other phases/pairs follow by CYCLIC ROTATION of the phase-reconstruction
   result (§17.6.3) — implementation SHALL rotate, never re-derive a new
   connection.
2. The driving voltage is the prefault positive-sequence voltage at the fault
   node, `Vf = Vf_prefault` (COMPLEX, magnitude AND angle), obtained by
   propagating the Task 5 per-case solved state (`LF360_GAT_OUT` /
   `LF360_GAT_IN`, one set per case) through the passive prefault network to
   the fault node. Flat-start `1∠0°` is FORBIDDEN. The SAME case-`c` prefault
   feeds all three sources for that case (Task 5 §9.6-a).
3. Negative- and zero-sequence networks contain NO internal EMF (Tasks 7/9).
   Only the positive network is excited (by the stage source of §19).
   The three networks couple ONLY at the fault node per §§17.2–17.5.

### 17.0.3 Thevenin quantities and two-solution rule

1. At fault node F and stage S, `Z1(F,S)` / `Z2(F)` / `Z0(F)` are the Thevenin
   sequence impedances SEEN FROM F (stage-dependent ONLY in `Z1`, because the
   generator positive reactance changes E''→E'→Eq per §19; `Z2`/`Z0` are
   passive and stage-invariant except for the Task 9 band end and the
   Task 10 dataset in force — both stated per run).
2. Implementation SHALL solve the FULL NODAL sequence networks (Ybus +
   source injection, per stage) for all bus/branch currents AND SHALL use the
   §§17.2–17.5 Thevenin scalars as an independent audit
   (`|I_nodal − I_thevenin| ≤ tol`). Thevenin-scalar-only solving is
   FORBIDDEN (it cannot represent F4 m-nodes, the GAT loop, or B-view
   branches correctly). Task 13 owns the tolerance.

### 17.0.4 Sign convention (binding, used by §§17.2–17.5 and §20)

1. Sequence currents `I1, I2, I0` at the fault are defined POSITIVE INTO THE
   FAULT (from the network into the fault branch / earth path).
2. Every network BRANCH contribution (sequence or phase) is defined POSITIVE
   TOWARD THE FAULT NODE along its leg (§20.1). Line through-reporting keeps
   the Task 11 GIS→remote positive sense ONLY for through-current tags and is
   re-signed toward-fault before the KCL sum.
3. Generator sign inside the EMF derivation (`It` leaving the machine,
   Task 5 §9.4.0) is a DERIVATION convention and SHALL NOT leak into the
   fault-network sign: at the network boundary the generator leg is re-signed
   per rule 2. Implementation SHALL document the re-signing step.

## 17.1 Three-phase fault LLL (bolted and resistive)

Connection: positive-sequence network ONLY, fault node to earth-reference
through `Zf_LLL` (three-phase fault impedance, §21.3). Negative and zero
networks are DEAD (no connection, no current).

```text
(17-1)  I1 = Vf / (Z1 + Zf_LLL)        [pu complex, INTO fault]
(17-2)  I2 = 0 ;  I0 = 0
(17-3)  V1F = Vf − I1·Z1  (= I1·Zf_LLL) [pu, positive-seq voltage AT fault node]
        V2F = 0 ;  V0F = 0              [at fault node; retained voltages at
                                        healthy buses come from the nodal
                                        solution, not from (17-3)]
(17-4)  Phase reconstruction (reference: all phases faulted symmetrically):
        Ia = I1 ;  Ib = a²·I1 ;  Ic = a·I1       [pu complex, INTO fault]
        |Ia| = |Ib| = |Ic| = |I1|  (audit: LLL phase symmetry, Task 13)
```

Stage label: (17-1)–(17-4) are evaluated ONCE PER STAGE with that stage's
`(Vf, Z1, source)` per §19 (`Ik''`: E''/Xd''; `Ib`: E'/Xd'; steady: Eq/Xd).
`ip` is NOT a fifth network solution — it derives from `Ik''` per §19.2.
Zf insertion: `Zf_LLL` enters UNDIVIDED (no 3× factor — three-phase path,
§21.3). Base run `Zf_LLL = 0` (bolted); sensitivity per §21.2.

## 17.2 Single-line-to-earth fault LG (reference phase A)

Connection: positive, negative, zero networks IN SERIES at the fault node,
through an earth-path impedance `3·Zf_LG` in the loop (§21.3). Reference
phase A faulted; B/C faults by rotation (§17.6.3).

```text
(17-5)  I1 = I2 = I0 = Vf / (Z1 + Z2 + Z0 + 3·Zf_LG)   [pu complex, INTO fault]
(17-6)  V1F = Vf − I1·Z1 ;  V2F = −I2·Z2 ;  V0F = −I0·Z0   [pu at fault node;
        audit: V1F + V2F + V0F = 3·Zf_LG·I0  (≡ 0 when Zf = 0)]
(17-7)  Phase reconstruction (A faulted):
        Ia = I1 + I2 + I0 = 3·I0     [faulted-phase current, INTO fault/earth]
        Ib = a²·I1 + a·I2 + I0 = 0   [healthy phases carry NO fault-branch
        Ic = a·I1 + a²·I2 + I0 = 0    current by construction; their retained
                                      bus voltages come from the nodal
                                      solution and are generally ≠ 0]
```

Notes: (a) `Z0` here is the FULL Thevenin zero seen from F INCLUDING the
generator `3·ZN` leg where the topology connects it (F1 LG/LLG), the GSUT/UAT/
GAT zero legs where gated, the Task 9 line band end, and the Task 10 grid-zero
band — per §§8–10 of Tasks 6/8/9, consumed unchanged. (b) NER current is part
of `I0`'s return, never a separate parallel fault current. (c) Stage rule as
§17.1 (one evaluation per RMS stage; `ip` derived per §19.2).

## 17.3 Line-to-line fault LL (reference pair B–C, no earth)

Connection: positive and negative networks IN PARALLEL (opposed) at the fault
node through inter-phase impedance `Zf_LL` (§21.3). Zero network DEAD
(`I0 = 0`, no earth path — including NER: no LG/LLG path is engaged).

```text
(17-8)  I1 = −I2 = Vf / (Z1 + Z2 + Zf_LL)   [pu complex, INTO fault]
        I0 = 0
(17-9)  V1F = Vf − I1·Z1 ;  V2F = −I2·Z2 = I1·Z2 ;  V0F = 0 (isolated, audit)
        audit: V1F − V2F = Zf_LL·I1  (≡ 0 when Zf = 0)
(17-10) Phase reconstruction (B–C faulted):
        Ia = I1 + I2 + I0 = 0
        Ib = a²·I1 + a·I2 + I0 = (a² − a)·I1 = −j·√3·I1
        Ic = a·I1 + a²·I2 + I0 = (a − a²)·I1 = +j·√3·I1 = −Ib
        audit: Ib + Ic = 0; |Ib| = |Ic| = √3·|I1|
```

Zf insertion: `Zf_LL` is the INTER-PHASE impedance, UNDIVIDED (no 3× factor).
Base run `Zf_LL = 0`; sensitivity per §21.2.

## 17.4 Double-line-to-earth fault LLG (reference pair B–C to earth)

Connection: positive network in SERIES with the PARALLEL combination of the
negative network and the (zero network + `3·Zf_LLG` earth path). Reference
pair B–C; other pairs by rotation.

```text
(17-11) Z0e = Z0 + 3·Zf_LLG                       [earth-return branch]
(17-12) I1  = Vf / (Z1 + (Z2 ‖ Z0e))
             = Vf·(Z2 + Z0e) / (Z1·Z2 + Z1·Z0e + Z2·Z0e)   [INTO fault]
(17-13) I2  = −I1 · Z0e / (Z2 + Z0e)               [INTO fault]
        I0  = −I1 · Z2  / (Z2 + Z0e)               [INTO fault, earth return]
        audit: I1 + I2 + I0 = fault-neutral residual path check per §20.3
(17-14) V1F = Vf − I1·Z1 ;  V2F = −I2·Z2 ;  V0F = −I0·Z0   [pu at fault node;
        audit: V1F = V2F = V0F + 3·Zf_LLG·I0  (≡ common voltage when Zf = 0)]
(17-15) Phase reconstruction (B–C to earth):
        Ia = I1 + I2 + I0                        [healthy phase: ≈ small,
                                                  ≡ 0 only for Z2 = Z0e]
        Ib = a²·I1 + a·I2 + I0                   [faulted phases]
        Ic = a·I1 + a²·I2 + I0                   [faulted phases]
        earth current Ie = Ia + Ib + Ic = 3·I0   [INTO earth, NER/grid/line
                                                  earth legs per §20.2]
```

Zf insertion: single earth impedance `Zf_LLG` common to both faulted phases
(STANDARD assumption, §21.3.4); any phase-to-phase component inside an LLG
arc is NEGLECTED by construction (limitation stated in §21.3.4). Base run
`Zf_LLG = 0`; sensitivity per §21.2. `Z0` content rule as §17.2-a.

### 19.1 `Ik''` — initial symmetrical short-circuit current (RMS, t = 0+)

Methodology: nodal solution of the SUBTRANSIENT sequence networks excited by
the Task 5 subtransient source. Positive network: `E''_c` behind
`Z'' = Ra + j·Xd''_sel` (PRIMARY `Xd''_sat = 0.2248 pu` machine base; Task 13-D
sensitivity `Xd''_unsat = 0.2608 pu`); classical round-rotor form per Task 5
§9.4.1 with the §9.4.1 saturation-mixing sensitivity. Negative network:
sourceless `Z2_gen = Ra + j·X2` (Task 7). Zero network: sourceless assembled
zero (Task 9) with NER/transformer/line-band/grid legs gated per topology.
Fault connection per §§17.1–17.4 with the stage's `(Vf, Z1, Z2, Z0)`.
Thevenin scalars (17-1)/(17-5)/(17-8)/(17-12) audit the nodal result.

Assumptions: (a) linear magnetics frozen at the prefault operating point
(saturated primary); (b) `E''` constant over the first cycles; (c) balanced
prefault (negative/zero driven only by the fault unbalance); (d) bolted base
`Zf = 0` (§21.1), sensitivity per §21.2; (e) passive R/X as inventoried
(no arc voltage, no breaker timing).

Limitations: (a) contains NO DC offset and NO peak information — `ip` is a
separate derived quantity (§19.2); (b) is an upper-bound RMS for downstream
decay stages, not a thermal equivalent on its own; (c) near-generator
saliency error is bounded by the Task 13-D variant, not eliminated;
(d) earth-fault magnitude inherits the FULL Task 9 zero-band + NER-tolerance
spread — a point `Ik''` for LG/LLG without its band is INCOMPLETE by design.

### 19.2 `ip` — peak short-circuit current (instantaneous first-peak magnitude)

Methodology: DERIVED from the `Ik''` result at the same fault, case, dataset,
band end, and `Zf` — NO separate network solution, NO separate source.
Let `R1(F) + j·X1(F) = Z1(F,Ik'')` be the Thevenin positive impedance at the
fault (from the `Ik''` network) and `r = R1/X1`:

```text
(19-1) κ(r) = 1.02 + 0.98·exp(−3·r)        [borrowed functional form, §19.5]
(19-2) ip   = κ · √2 · Ik''                 [kA peak magnitude, same location/
                                             phase as the governing Ik'']
```

The governing `Ik''` is the faulted-phase RMS for LG (`|Ia|`), the faulted-
phase RMS for LL/LLG (`max(|Ib|,|Ic|)`), and the phase RMS for LLL (`|I1|`).
`r` is evaluated from the FAULT-NODE Thevenin `Z1` (not from any single
branch R/X). Three-phase `κ` form is used for ALL fault types as a UNIFORM
design definition (limitation (c)).

Assumptions: (a) single-exponential DC decay dominated by the fault-node
`X/R`; (b) prefault load current neglected in the peak increment;
(c) no change of network between `t = 0+` and the first peak.

Limitations: (a) `ip` is a MAGNITUDE, not a phasor — phasor arithmetic on
`ip` is FORBIDDEN; (b) the `κ(r)` SHAPE is borrowed from the IEC far-from-
generator peak form but is NOT an IEC-compliant `ip`: voltage factor `c`,
motor infeed, correction factors, and exact DC-transfer across the GSUT/UAT/
GAT are MISSING (§19.5) — `ip` SHALL be labelled `design-defined peak per
§19.2`, never `IEC 60909 ip`; (c) near-generator asymmetry (decaying AC +
DC with different time constants, salient subtransient paths) is NOT
captured — `ip` at F1/F2 carries this stated under-capture risk and SHALL be
reported with its `r` and `κ` so the reviewer sees the basis; (d) earth-path
R (NER-dominated at F1) does not enter `r` — `ip` for LG/LLG inherits the
positive-network `r` by definition, a documented simplification.

### 19.3 `Ib` — breaking current (RMS symmetrical at break delay)

Methodology: nodal solution of the TRANSIENT-stage sequence networks at a
PRESCRIBED break time `t_break`, excited by the Task 5 transient source.
Positive network: two-axis `E'd_c/E'q_c` behind `Xd'/Xq'` per Task 5 §9.4.2
(documented `Xd'`-only fallback ONLY under that section's approximation +
sensitivity conditions). Negative/zero networks: same passive form as §19.1
(stage-invariant). Fault connection per §§17.1–17.4 with the transient
`(Vf', Z1', Z2, Z0)` — note `Vf'` is the transient-stage drive propagated
from `E'`, NOT a re-derivation from a new load flow. `t_break` is a
PROTECTION-STAGE INPUT parameter (Task 14 handoff), NOT fixed here; the
implementation SHALL accept `t_break` and report `Ib(t_break)` with the
`t_break` value attached. NO decay-multiplier (`µ`/`q`) post-processing is
applied in the base definition — decay E''→E' is embodied by the
source/reactance swap itself. Workbook time constants (`Td0'`, `Tq0'`, …)
parameterise BETWEEN-stage behaviour and are Task 13 sensitivity context
only, not `Ib` inputs.

Assumptions: (a) `E'` held constant through the break delay (no further decay
E'→Eq inside the delay — stated conservative simplification, i.e. `Ib` is an
UPPER bound for its stage); (b) topology frozen between fault initiation and
`t_break` (no switching, no breaker action modelled); (c) same linearity and
`Zf` rules as §19.1.

Limitations: (a) contains NO DC component at contact parting and NO arc
voltage — it is a symmetrical-RMS delayed quantity, not an interrupting-duty
rating input on its own; (b) constant-`E'` over the delay OVERSTATES `Ib`
for long delays — the steady-state bound (§19.4) brackets the far end;
(c) the `Xd'`-only fallback (where permitted) carries the Task 5 §9.4.2
56 %-spread saliency error into `Ib` — permitted ONLY with the mandated
two-axis sensitivity; (d) SHALL never be labelled with a breaker rating or a
pass/fail verdict here (Task 14 handoff carries currents + `t_break`, no
duties).

### 19.4 `Ik-steady` — sustained (steady-state) short-circuit current (RMS)

Methodology: nodal solution of the SYNCHRONOUS-stage sequence networks
excited by the Task 5 constant-field source `Eq_c` behind `Xd/Xq`
(Task 5 §9.4.3 form: `Vd = −Xq·Iq`, `Vq = Eq − Xd·Id`, +Ra per convention).
Negative/zero networks: same passive form as §19.1. Fault connection per
§§17.1–17.4 with `(Vf_eq, Z1_sync, Z2, Z0)`.

Assumptions (binding): CONSTANT FIELD — `Eq_c` held at its prefault value
through the fault (no AVR forcing, no governor/SFC action — OUT OF SCOPE per
Global Constraints). Open-circuit-saturation refinement via `S10/S12` is NOT
part of the base derivation (Task 5 §9.4.3). `Rf` SHALL NOT enter on any base.

Limitations: (a) UNDERSTATES sustained current where AVR forcing would raise
the field, OVERSTATES it where protection/field collapse would lower it —
`Ik-steady` is therefore a CONSTANT-FIELD REFERENCE, not a field-forced
rating; any excitation-forcing variant is Task 13 sensitivity with
ENGINEERING_ASSUMPTION label, never the base; (b) longest-time bound only —
thermal/duration use belongs to Task 14 handoff with explicit duration data,
not to this section; (c) SHALL never be mixed with `Ik''` or `Ib` in one
"current" column without its stage label.

## 21. Fault impedance `Zf` (answers Q15)

### 21.1 Base: bolted fault `Zf = 0` (binding)

The BASE fault study at every location × type × stage uses `Zf = 0`
(bolted metallic fault). Rationale: maximum symmetrical current
(conservative for duty handoff), reproducible audit baseline for the Task 13
continuity legs (F3↔m=0, F5↔m=1), and the only impedance assumption that
adds no new data. Status: DESIGN BASE (not a measurement claim).

### 21.2 Nonzero sensitivity `Zf_sens` (binding — ≥1 justified probe)

At least ONE nonzero `Zf` sensitivity SHALL be run wherever the fault
topology engages the impedance (all four types; LG/LLG earth paths
mandatory). The probes below are ENGINEERING_ASSUMPTION sensitivity inputs —
justified test magnitudes, NOT measured footing/arc data. No probe SHALL be
presented, plotted, or handed off as a "realistic fault resistance".

| Probe | Value | Unit / base | Status | Justification (why this magnitude) |
|---|---|---|---|---|
| `Zf_earth_sens` (LG + LLG earth path) | 5 ohm resistive | ohm at fault voltage level (pu via §17.0.1.2) | ENGINEERING_ASSUMPTION | Order-of-tower-footing-plus-arc probe for 230-kV earth faults: large enough to move LG/LLG current visibly where the loop is line/grid-dominated (F3/F4/F5), small enough to demonstrate NER dominance where the generator neutral leg dominates (F1 LG: `3·ZN ≈ 3×60-ohm-class ≫ 3×5 ohm`, so the probe correctly shows LOW sensitivity — itself a validation leg). No footing measurement is claimed. |
| `Zf_phase_sens` (LL inter-phase + LLL three-phase) | 1 ohm resistive | ohm at fault voltage level | ENGINEERING_ASSUMPTION | Small arc-path probe: tests phase-fault sensitivity without masking the bolted maximum. For LLL it enters undivided; for LL as inter-phase `Zf_LL`. |

Rules: (a) sensitivity runs REPEAT the base run with ONLY `Zf` changed
(same case, dataset, band end, `Xd''` role, `m`); (b) `Zf` is PURELY
RESISTIVE in both probes (arc/footing physics is resistive at power
frequency to this study's fidelity — reactance in `Zf` would need a
physical justification that does not exist); (c) Task 13-F exercises
`Zf = 0` vs probes per location; additional values MAY be added ONLY via the
Task 13 compact matrix with recorded reason — never an uncontrolled sweep.

### 21.3 `Zf` insertion table (binding — where each probe enters)

|---|---|---|---|---|

### 21.4 LLG modelling assumption (binding limitation)

A single earth impedance common to both faulted phases is assumed; any
phase-to-phase impedance component inside an LLG arc channel is NEGLECTED by
construction. Rationale: no arc-channel data supports a two-impedance LLG
model, and the bolted base plus the earth-probe bracket the credible range.
This limitation SHALL travel with every LLG result as a footnote.

## 20. Source contributions (answers Q17)

### 20.1 Direction convention (binding)

1. Every contribution leg is reported POSITIVE TOWARD THE FAULT NODE.
   The fault current itself is POSITIVE INTO THE FAULT (§17.0.4).
2. Transformer/complex-topology legs keep their physical branch identity
   (HV side vs LV side reported separately where both exist) and are each
   re-signed toward-fault before summation — a leg whose natural load-flow
   direction points away from the fault therefore appears with a negative
   real part, which is CORRECT and SHALL NOT be "rectified".
3. Line through-reporting keeps GIS→remote positive ONLY for the
   protection-stage through tag (`LINE-Q9` label, §20.5); the KCL sum uses
   the toward-fault re-signed values.

### 20.3 Computation + sum-to-fault consistency (binding)

1. Method: FULL NODAL sequence solution per stage (§17.0.3.2) → extract each
   leg's sequence branch currents (already toward-fault signed) → phase
   reconstruction per leg via (17-16) → report per-leg phasors (RMS stages)
   with unit/base/stage label.
2. KCL asserts (implementation SHALL assert, Task 13 SHALL validate):
```text
(20-1) Per sequence s ∈ {1,2,0}:  Σ_legs Is_leg  ≡  Is_fault   (tolerance)
(20-2) Per phase p ∈ {a,b,c}:     Σ_legs Ip_leg  ≡  Ip_fault   (tolerance)
(20-3) Earth check (LG/LLG):      Σ_legs 3·I0_leg ≡ Ie = 3·I0_fault
(20-4) LLL symmetry: |Ia| ≈ |Ib| ≈ |Ic|; LL: Ib + Ic ≈ 0; LG: Ib_branch =
        Ic_branch = 0 AT THE FAULT BRANCH (legs individually nonzero)
```
3. Superposition-by-source (Thevenin-per-source) decomposition is permitted
   ONLY as an audit cross-check, never as the base computation (it mishandles
   the F4 two-branch network and the GAT loop unless the full topology is
   retained — audit only).

   `Ik-steady`); `ip` has NO contribution table (derived magnitude, §19.2 —
   reporting `ip` per leg is FORBIDDEN).
