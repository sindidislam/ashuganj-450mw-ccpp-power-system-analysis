## 9.1 Review-gate answers (binding)

- **Q1 — How is the generator internal EMF obtained?**
  The internal source is DERIVED per prefault case from the ACTUAL solved Phase-3
  prefault load-flow state (primary pair `LF360_GAT_OUT` / `LF360_GAT_IN`), as
  stored in `results/phase3_loadflow/phase3_bus_results.csv` (54 rows) and
  `results/phase3_loadflow/phase3_system_summary.csv` (6 rows) plus
  `phase3_loadflow_results.mat`. Method: complex terminal voltage
  `Vt = |Vt| ∠ θt` at bus `B22` (magnitude AND angle) combined with dispatched
  complex power `St = P + jQ` at the generator terminals via the Thevenin
  relation `E = Vt + Z_gen · It` with `It = conj(St / Vt)` in consistent pu
  (equations §9.4). One EMF set per prefault case — never a single averaged EMF,
  never a flat-start `1∠0°`, never a recomputed unrelated load flow.
- **Q2 — Which Xd'' is used?**
  PRIMARY fault-study source uses **Xd''_sat = 0.2248 pu** on the 458 MVA /
  22 kV machine base (workbook row 3 K3, DUAL-ATTESTED by the Siemens extract
  §2.1.1 subtransient synchronous reactance (sat.) 22.48 %). Rationale: faults
  initiate from ≈1.00 pu terminal voltage where the iron is saturated; the
  saturated reactance is the correct initial-condition value (§9.5).
  SENSITIVITY case uses **Xd''_unsat = 0.2608 pu** (workbook row 3 J3,
  WORKBOOK-DERIVED + QUALIFIED, no Siemens corroboration) to bound the
  high-impedance / low-current end and to cover the QUALIFIED base/saturation
  interpretation. The two values are NEVER averaged or merged. The legacy-registry
  0.2248 triple (`ashuganj_generators.m:34-36`) is numerically identical because
  it transcribes the SAME Siemens saturated table — not an independent
  corroboration, never a third case.

## 9.4 EMF-from-prefault method (normative equations — design, no numerics)

Notation: pu on the machine base unless stated. `j = √−1`. Angles in radians
in equations (deg → rad × π/180 at extraction). `conj` = complex conjugate.
`St` is power LEAVING the machine (generator sign, +P delivering).

### 9.4.0 Common prefault quantities (all three sources share these)

```text
(9-1)  |Vt_c|  = V_B22_kV(c) / 22                        [pu, machine V-base]
(9-2)  θt_c   = Angle_deg(B22,c) × π/180                [rad, slack BGRID230 = 0]
(9-3)  Vt_c   = |Vt_c| · (cos θt_c + j·sin θt_c)         [pu complex, RETAIN angle]
(9-4)  St_c   = P_gen_MW(c) + j·Q_gen_MVAr(c)            [MVA, generator sign]
(9-5)  St_c_pu= St_c / 458                               [pu, Snom = 458 MVA]
(9-6)  It_c   = conj(St_c_pu / Vt_c)                     [pu, current leaving machine]
```

Rules: (a) `|Vt|` and `θt` SHALL both be read from the solved case — an
`|V|`-only or `1∠0°` substitution is forbidden. (b) `P/Q` SHALL be the case's
own solved dispatch — never the 360 MW nameplate alone, never the other GAT
state's Q, never a capability-limit value. (c) Division `St/Vt` is complex with
`Vt` complex — the STAR operation `Vprefault/Xd''` (magnitude divided by a
reactance, no current, no angle) is FORBIDDEN without the derivation (9-1)–(9-6).

### 9.4.1 Initial / subtransient source E'' (feeds Ik'')

```text
(9-7)  Z''_sel   = Ra_pu_mach + j·Xd''_sel               [pu, machine base]
(9-8)  E''_c     = Vt_c + Z''_sel · It_c                 [pu complex, machine base]
```

- `Xd''_sel`: PRIMARY `Xd''_sat = 0.2248`; SENSITIVITY `Xd''_unsat = 0.2608`
  (§9.5). `Ra_pu_mach = 0.00089 / Zbase_machine`, `Zbase_machine = 22²/458`
  (≈1.05677 ohm, equation only — Task 4 §6.3). Ra SHALL be retained in the
  derivation; omission in the fault network per stage needs the Task 12
  justification — never silent.
- Form (9-8) is the positive-sequence (round-rotor) subtransient Thevenin. It is
  the PRIMARY representation for the sequence network, justified as the
  classical subtransient approximation: workbook `Xd''_unsat 0.2608` vs `Xq''`
  0.2593 differ by 0.6 % (round-rotor error negligible). With the PRIMARY
  saturated selection the d/q spread is larger (`0.2248` vs `Xq'' 0.2593`,
  ≈15 % — `Xq''` saturation UNQUALIFIED_IN_SOURCE, Task 4 §6.1 row 9) — the
  design therefore REQUIRES the Task 13-D sensitivity (unsaturated pair and/or
  salient `Zq'' = Ra + jXq''` variant) so the saturation-mixing error is bounded,
  not hidden. No third Xd'' value is introduced.
- `E''_c` is a COMPLEX phasor (magnitude + angle), one per case `c`. Its angle
  is generally NOT equal to `θt_c` — the implementation SHALL carry it.

### 9.4.2 Transient source E' (feeds Ib)

Saliency CANNOT be neglected here (`Xd' 0.3256` vs `Xq' 0.5087`, 56 % spread).
The normative source is therefore TWO-AXIS. With the prefault Park angle `δc`
from the classical `Xq`-projection:

```text
(9-9)  δc       = arg( Vt_c + (Ra_pu_mach + j·Xq) · It_c )   [rad, Xq = 1.7510 pu]
(9-10) Vd_c     = |Vt_c| · sin(θt_c − δc)                    [pu, d-axis terminal V]
       Vq_c     = |Vt_c| · cos(θt_c − δc)                    [pu, q-axis terminal V]
       Id_c     = |It_c| · sin(∠It_c − δc + π/2) …           [pu, Park projection of It_c]
       Iq_c     = |It_c| · cos(∠It_c − δc + π/2) …           [pu, ditto]
         (implementation SHALL state its Park sign convention explicitly and use
         it consistently; the equations above fix INTENT, Task 14 fixes code form)
(9-11) E'd_c    = Vd_c + Xq' · Iq_c   (+ Ra terms per convention)   [pu, Xq' = 0.5087]
       E'q_c    = Vq_c − Xd' · Id_c   (+ Ra terms per convention)   [pu, Xd' = 0.3256]
```

- `E'd_c, E'q_c` together are the transient source for case `c`. For a
  positive-sequence-only fault engine that cannot carry two axes, the design
  PERMITS the documented fallback `E'_c = Vt_c + (Ra + j·Xd')·It_c` as an
  APPROXIMATION with mandatory Task 13-D sensitivity (Xd'-only vs two-axis) and
  an explicit non-compliance note — never presented as exact. Saliency
  (`Xd ≠ Xq`) is otherwise preserved (Task 4 §6.4.1); no silent round-rotor
  (`Xq' = Xd'`) substitution.
- Time constants (`Td0' 7.547 s, Tq0' 0.839 s, Td' 1.213 s, Tq' 0.214 s` …,
  workbook Y3–AF3) are NOT source inputs — they parameterise decay BETWEEN
  stages, whose methodology belongs to Task 12. This section supplies the
  `t = 0+transient` anchor only.

### 9.4.3 Steady-state (synchronous) source Eq (feeds sustained current)

```text
(9-12) Eq_c  ≡  E'q_c sustained-field projection: field EMF behind Xd (d-axis),
                with Xq = 1.7510 on the q-axis (Xd = 1.7830, Xq = 1.7510 pu)
(9-13) Form: Vd_c = −Xq · Iq_c (+ Ra);  Vq_c = Eq_c − Xd · Id_c (+ Ra)
              ⟹ Eq_c derived from (Vd_c,Vq_c,Id_c,Iq_c) of (9-10) with Xd/Xq.
```

- Assumption (binding): CONSTANT FIELD — `Eq_c` is held at its prefault value
  through the fault (no AVR action, no governor action). AVR/governor/SFC
  response is OUT OF SCOPE per Global Constraints; any excitation forcing is
  Task 12 sensitivity-only with ENGINEERING_ASSUMPTION label, never the base.
- Saturation coefficients `S10/S12` (workbook AI3/AJ3) are source coefficients
  only, not a measured OCC (`ashuganj_generators.m:118`) — open-circuit
  saturation refinement of `Eq` is NOT part of the base derivation.
- Field-base-unresolved `Rf_numeric 0.10631` (workbook V3, UNRESOLVED) SHALL NOT
  enter any source equation, on any base, with any conversion.

### 9.4.4 Worked symbolic check (no new numerics — structure only)

For auditability the implementation SHALL log per case `c`:
`(|Vt|, θt, P, Q) → (Vt, St_pu, It) → (E'', E'd/E'q, Eq)` with units and base
at each arrow, so a reviewer can re-derive every phasor from §9.3 fields alone.
Logging the three source magnitudes WITHOUT the derivation chain does not
satisfy this section.

### 9.4.5 Base transfer to the fault network (equation form only)

- EMF (voltage) in pu at the 22-kV level transfers NUMERICALLY UNCHANGED between
  S-bases at the same voltage level (`Vpu = Vactual / 22 kV` is S-independent).
- Impedances transfer by the S-ratio at the same voltage level:
  `Z_sys_pu = Z_mach_pu × (S_sys / S_mach)` (Task 4 §6.3.3); across voltage
  levels (22 kV ↔ 230 kV through the GSUT) the implementation SHALL state the
  voltage-ratio treatment explicitly. Converted fault-study NUMBERS are not
  computed here — Task 14 owns them.
