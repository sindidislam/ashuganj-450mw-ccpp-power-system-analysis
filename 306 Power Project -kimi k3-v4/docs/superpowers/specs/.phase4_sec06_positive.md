## 6.3 Base conventions + conversion equations (design, no new numerics)

1. Machine base: S = 458 MVA, V = 22 kV → Zbase_machine = V²/S (ohm). Status QUALIFIED
   interpretation (no separate literal base declaration in source).
2. Network base (frozen): S = 100 MVA, V = 230 kV → Zbase = 529 ohm (DERIVED arithmetic,
   frozen per Task 1).
3. Reactance transfer (same voltage level): X_sys_pu = X_mach_pu × (S_sys / S_mach).
   Across voltage levels the implementation SHALL state the voltage-ratio treatment
   explicitly; Task 4 fixes the equation form only, not converted fault-study numbers.
4. Transformer % figures convert on their own rating first (X = sqrt(Z² − R²) in pu on
   rating), then to the study base by the same S-ratio rule; the implementation design
   (MATLAB architecture) is Task 14's, not this section's.
5. Ra transfer: Ra_pu_machine = Ra_ohm / Zbase_machine; Ra_pu_100MVA = Ra_ohm / (22²/100).
   Whether Ra is retained or justifiably neglected per stage is an implementation
   decision with mandatory justification — it SHALL NOT be dropped silently.
