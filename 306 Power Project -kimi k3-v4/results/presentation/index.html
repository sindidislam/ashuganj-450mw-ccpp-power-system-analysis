A clear route through the results

1. Establish the condition

Read the source availability, fault location/type, GAT state and electrical profile.

2. Read the electrical stress

Compare RMS fault current, source/branch contribution and the stated MVA quantity.

3. Follow the protection

Read pickup → trip request → breaker command → measured current cessation, alongside DC availability.

Use the right comparison

Relay settings change clearing behavior, not the initial prospective fault current. Before/after plots compare timing and observed response. Different network profiles and time windows are identified.
